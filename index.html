REFERENSI POD HD500

Tempo & efek

Panel menampilkan nilai rekomendasi otomatis. Pengaturan tempo mengikuti konsep POD HD500: sinkronisasi tiap efek terpisah dari pilihan sistem Preset/Global.

  • Delay Time: Off = ms, atau pilih pembagian not untuk mengikuti Tap Tempo.
  • Dynamic Delay: L Time dan R Time punya Tempo Sync masing-masing.
  • Stereo Delay: Sync Left dan Sync Right independen.
  • Trails: On mempertahankan ekor Delay/Reverb saat model dimatikan.

Pilihan sistem Tempo Sync dan BPM Global disimpan di browser; BPM Preset, Trails, dan pembagian not per blok ikut tersimpan bersama preset.

05 / DEVICE FILES

Impor file POD HD500

H5E · H5S · H5B

Unggah preset asli .h5e, Set List .h5s, atau Bundle .h5b dari POD HD500 Edit. Alat ini akan memeriksa jenis file, ukuran, signature, dan fragmen teks yang terbaca.

Belum ada file dipilih.

Penting: format preset Line 6 bukan JSON terbuka. Versi ini belum mengubah byte .h5e menjadi parameter amp/efek, dan tidak membuat file .h5e palsu. Untuk mengembangkan pembaca penuh, perlu sampel file .h5e asli dari perangkatmu untuk menguji hasil decode.

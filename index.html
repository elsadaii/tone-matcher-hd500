Parameter ditampilkan sesuai model yang dipilih. Isi nilai persis seperti yang terlihat pada layar POD HD500; satuan/rentang hanya dicantumkan bila didukung manual.

CATATAN PARAMETER

Nilai sesuai layar POD

Kolom parameter disimpan sebagai angka/teks yang kamu masukkan. Guide resmi menjelaskan nama kontrol dan fungsi, tetapi tidak memberikan satu rentang numerik universal untuk semua knob/model.

  • Drive, Bass, Mid, Treble, Presence, Volume
  • Power amp: Master, Sag, Hum, Bias, Bias Excursion
  • Cab: Early Reflections, Cab, Mic

Untuk beberapa amp, label knob berubah mengikuti desain amp (misalnya CUT atau TONE).

05 / DEVICE FILES

Impor file POD HD500

H5E · H5S · H5B

Unggah preset asli .h5e, Set List .h5s, atau Bundle .h5b dari POD HD500 Edit. Alat ini akan memeriksa jenis file, ukuran, signature, dan fragmen teks yang terbaca.

Belum ada file dipilih.

Penting: format preset Line 6 bukan JSON terbuka. Versi ini belum mengubah byte .h5e menjadi parameter amp/efek, dan tidak membuat file .h5e palsu. Untuk mengembangkan pembaca penuh, perlu sampel file .h5e asli dari perangkatmu untuk menguji hasil decode.
